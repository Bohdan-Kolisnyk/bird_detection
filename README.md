# Bird Detector

Задача із донавчання моделі YOLO26n для детекції одного класу - птахів.
Було використано датасет із Kaggle (з ліцензією Apache 2.0 - доступний для поширення) та модель YOLO26n з бібліотеки [ultralytics].
Інструкції встановлення та використання репозиторію нижче.

## Датасет

Було використано публічний датасет із Kaggle:
https://www.kaggle.com/datasets/samuelayman/bird-dataset

Цей датасет містить 950 зображень птахів та анотації у форматі YOLO. 
Хоч розмітка й була у вже необхідному форматі [class_id x_center y_center width height], class_id всюди був 24 замість 0. 
Це було виправлено скриптом `scripts/correct_labels.py`.

Також, датасет був поділений на тренувальну та валідаційну частини у співвідношенні 80/20 скриптом `scripts/train_val_splitter.py`

В результаті отримано такі дані:
760 зображень для train
190 зображень для val
Роззмітка у форматі [0, x, y, w, h]

## Навчання

Використана модель YOLO26n з бібліотеки [ultralytics] була донавчена локально.
Основні параметри донавчання:
Епохи - 100 
imgsz=640
batch=16

## Валідація та метрики

За 100 епох навчання, модель спромоглась досягти непоганих результатів на валідаційній частині датасету:

Precision - 0.87 
Recall - 0.734 
mAP50 - 0.852 
mAP50-95 - 0.667 

Дані результати модель показала близько 79 епохи навчання.
Найкращі ваги моделі збережено у `weights/best.pt`

У підсумку, модель вийшла доволі обережною, оскільки за рахунок високого precision та трохи нижчого recall, вона рідше помиляється хибно, але пропускає частину птахів.

## Використання моделі

Для наочної перевірки роботи моделі було завантажено 3 відео із птахами із безкоштовної платформи Pexels 
Посилання на оригінальні відео: 

input - двоє птахів на дроті.
https://www.pexels.com/uk-ua/video/38193210/ 

input_2 - чорно-біле відео зграї птахів у польоті над водою.
https://www.pexels.com/uk-ua/video/10209168/

input_3 - двоє птахів у лісі серед дерев та гілок.
https://www.pexels.com/uk-ua/video/37757503/

Дані відео було оброблено моделлю у скрипті `predict_video.py` та збережено результати у папці `examples/`

Команда для запуску скрипту:

```bash
python predict_video.py --input examples/input.mp4 --output examples/output.mp4
```

Також додано параметр `--weights`, який за замовчуванням бере найкращі збережені ваги моделі із`weights/best.pt`, проте за бажання можна використати інші.

## Використання репозиторію та скриптів

Для повноцінного використання репозиторію та скриптів внизу надано почерговий перелік команд для встановлення віртуального середовища,встановлення необхідних бібліотек та запуску коду:

```bash
git clone .....

python -m venv venv
venv\Scripts\activate  # для ОС Windows

pip install -r requirements.txt # встановлення необхідних бібліотек

python scripts/correct_labels.py  # виправлення class_id у розмітці датасету (необхідно лише для повторної підготовки датасету)

python scripts/train_val_splitter.py  # поділ датасету на train та val (необхідно лише для повторної підготовки датасету)

python train.py  # донавчання моделі на датасеті(модель донавчена локально, та ваги збережено, повторний запуск не є необхідним)

python predict_video.py --input examples/input.mp4 --output examples/output.mp4  # інференс моделі на відео
```


## Висновки та подальші кроки

- Сама модель YOLO26n вже претренована на COCO, тому навіть з невеликою кількість додаткових даних змогла продемонструвати непоганий бейзлайн результатів.
- На відео-прикладі модель добре детектить птахів та коректно відображає bounding box.
- Модель здатна детектити декілька птахів одночасно, динамічно змінюючи розмір bounding box під час їхнього руху.
- Модель схильна частіше пропускати об'єкти, що знаходяться ближче до країв кадру або які видимі частково.
- Відео examples/output_3.mp4, показало, що модель пропускає птаха, через складний фон - гілки та листя.
- Інференс моделі доволі швидкий, проте повний пайплайн обробки відео: читання + інференс + запис, продемонстрував швидкість недостатню для роботи в реальному часі - 157 кадрів оброблено за 33.6с, 419 кадрів за 75с та 187 кадрів за 43.5с.
- Метрики показали, що модель рідко хибно помиляється проте може пропускати об'єкти. 
- Серед найефективніших покращень варто виділити: більшу кількість даних, довше навчання, та аугментації даних, а також зменшення imgsz при інференсі для збільшення швидкості роботи моделі.
